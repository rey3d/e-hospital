Important libraries for Full Stack Project

1) Mongoose
	->It helps Node.js to communicate with Mongodb easily.(Using Complete mongodb will be messy.)
	=>Need to see the basic syntax of Mongoose
2) Cors (Cross Origin Resource Sharing)
	->It allows the react frontend to connect with express backend.
	-> React runs on port "3000" & Express on "5000".
3) dotenv
	->Helps in storing the secret data in environment variables in (.env) files.
4) jswebtoken (JWT)
	->JWT used for login authentication.
	=>Working of this 
		When user logs in:
			1) Server verifies password
			2)  Server sends a token
		Example token:eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
		User sends this token with every request.
5) bcryptjs
	->encrypts passwords before storing in the database.

extra one module ""

6) npm install nodemon --save-dev  
	->nodemon is a tool that automatically restarts your server when you change your code.
	->"--save-dev " -> This means install as a development dependency.

*** URI instead of URL because it is "URI = Uniform Resource Identifier" It is a standard format used to connect to resources like databases.

user logins (email & password) -> server responds with (JWT token) -> this token is used for other operations.

structure of the JWT token -> eyJhbGciOiJIUzI1NiJ9.eyJpZCI6IjEyMyIsInJvbGUiOiJkb2N0b3IifQ.xyzABC123

it has three parts 1. header -> algorithm used , 2. payload -> payload + role, 3.  signature -> proves it was not tampered.

React (frontend)
      ↓  "Hey, log this user in"
   Axios  ←--- messenger
      ↓  sends HTTP request
Express (backend)
      ↓  processes it
   Axios  ←--- brings back the response
      ↓
React gets the data and shows it on screen

Flow in our application

User clicks Login button
        ↓
Login.jsx calls → API.post("/auth/login", { email, password })
        ↓
axios.js adds baseURL → http://localhost:5000/api/auth/login
        ↓
Backend receives request → verifies → sends back token
        ↓
We save token to localStorage
        ↓
Every future request → axios.js automatically adds token to header
        ↓
Backend sees token → allows access to protected routes
